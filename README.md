# 1-I-have-a-new-quest-write-code-in-Python-
Обучение (написать код для калькулятора скидок с валидацией)
Пользователь вводит цену и процент скидки. Программа считает итоговую цену, но должна проверять: цена ≥ 0, скидка от 0 до 100. Если ввод некорректный — выводить понятное сообщение.
Навыки: input(), преобразование типов, условия if/else, обработка ошибок.
